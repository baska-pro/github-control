# Screenshots

Folder ini digunakan untuk screenshot tampilan GitHub Control Bot.

## Rekomendasi file

- `01-home-menu.png` — menu utama Telegram
- `02-repository-list.png` — daftar repository
- `03-repository-overview.png` — detail repository aktif
- `04-file-manager.png` — File & Folder Manager
- `05-create-file.png` — alur pembuatan file
- `06-upload-media.png` — upload media ke repository
- `07-git-operations.png` — Git operations
- `08-actions.png` — GitHub Actions
- `09-security.png` — security dashboard
- `10-account-switcher.png` — multi-account GitHub

## Format

- Gunakan PNG atau WebP.
- Lebar ideal 1080–1440 px.
- Jangan menampilkan token, `.env`, Telegram bot token, PAT GitHub, private key, credential, atau informasi sensitif lain.
- Jika screenshot berasal dari Telegram, crop area yang relevan agar teks tetap mudah dibaca.

Setelah screenshot tersedia, README utama dapat menampilkan galeri gambar dari folder ini.
